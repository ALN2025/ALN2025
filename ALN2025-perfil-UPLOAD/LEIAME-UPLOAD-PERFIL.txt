O que fazer no GitHub
---------------------
1. Abre: https://github.com/ALN2025/ALN2025

2. Add file > Upload files

3. Arrasta para a RAIZ desse repositório a pasta:
      profile-readme-assets
   (com todos os SVG listados acima)

   Importante: o caminho final no GitHub tem de ficar, por exemplo:
      ALN2025/ALN2025/profile-readme-assets/cmd-window-banner.svg

4. Commit changes (branch main, ou master se for o teu padrão).

5. Se o README usar o link com "main" e o teu repo for "master", edita o README e troca
   main por master na URL do <img> do banner, ou renomeia o branch para main.

6. Se ainda tiveres cmd-team-l2jaln-part2.svg no repo, podes apagá-lo (o PROFILE_README_git5_linux.md já não o usa).
